# Modelo aprovado do relatório Meta Ads

Aprovado pelo gestor em 13/11/2026. Todo relatório novo deve seguir este visual e esta estrutura.

Arquivos:
- `modelo-aprovado.pdf`: PDF completo de 4 páginas (dados fictícios).
- `pagina-1.png` a `pagina-4.png`: cada página como imagem, para consulta rápida.
- `dados-do-modelo.json`: os dados que geraram o modelo (mesmo formato que o Midas preenche com dados reais).

Páginas: 1 resumo, 2 Instagram (topo), 3 vídeo (meio), 4 WhatsApp (fundo).
Para regenerar: `python3 relatorio/gerar.py relatorio/modelo-aprovado/dados-do-modelo.json`
